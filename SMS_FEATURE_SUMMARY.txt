═══════════════════════════════════════════════════════════════════════════
                       TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ISSUE: SMS not received
FIX:
  1. Check console logs for errors
  2. Verify mobile number format (10 digits, starts with 6-9)
  3. Check SMS API credentials
  4. Verify SMS balance in provider account
  5. Check internet connectivity

ISSUE: "Invalid credentials" error
FIX:
  1. Update SMS_USER and SMS_PASSWORD in SMSUtil.java
  2. Verify credentials in SMS provider dashboard
  3. Rebuild and redeploy project

ISSUE: Admin SMS panel not accessible
FIX:
  1. Verify logged in as admin
  2. Check URL: /admin/send-sms.jsp
  3. Verify SendSMSServlet.java is compiled
  4. Check servlet mapping in web.xml or @WebServlet annotation

ISSUE: Character counter not working
FIX:
  1. Check browser console for JavaScript errors
  2. Verify send-sms.jsp loaded correctly
  3. Clear browser cache and retry
