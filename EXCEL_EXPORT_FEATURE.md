# Excel Export Feature for Unused Licenses

## 📋 Overview

A new feature has been added to export unused (unassigned) licenses to Excel or CSV format. This allows administrators to download and distribute license keys easily.

---

## ✨ Features

### What You Can Do
- ✅ **Download unused licenses** in Excel format (.xls)
- ✅ **Download unused licenses** in CSV format (.csv)
- ✅ **Export only available licenses** (not used/assigned)
- ✅ **One-click download** from admin dashboard
- ✅ **Timestamped filenames** for easy tracking

### What's Included in Export
- License Key (e.g., EMS12345)
- Status (active)
- Generated Date
- Generated By (admin name)

---

## 🎯 How to Use

### For Administrators

#### Method 1: From Statistics Card
1. Login as admin
2. Go to **Manage Licenses** page
3. Look at the **"Available"** statistics card (green card)
4. Click **"Download Excel"** button
5. File downloads automatically

#### Method 2: From Export Section
1. Login as admin
2. Go to **Manage Licenses** page
3. See **"Export Unused Licenses"** section (green border)
4. Choose format:
   - Click **"Download Excel"** for .xls format
   - Click **"Download CSV"** for .csv format
5. File downloads automatically

### Servlet Parameters

**URL Pattern:**
```
/ExportLicensesServlet?format=excel
/ExportLicensesServlet?format=csv
```

**Parameters:**
- `format` - "excel" or "csv" (default: csv)

**Response Headers:**

For Excel:
```
Content-Type: application/vnd.ms-excel
Content-Disposition: attachment; filename="unused_licenses_[timestamp].xls"
```

For CSV:
```
Content-Type: text/csv
Content-Disposition: attachment; filename="unused_licenses_[timestamp].csv"
```

## 📊 Database Query

The export feature uses this query:

```sql
SELECT l.*, u1.full_name as generated_by_name
FROM licenses l
LEFT JOIN users u1 ON l.generated_by = u1.user_id
WHERE l.status = 'active' AND l.is_used = FALSE
ORDER BY l.generated_date DESC
```

**Filters:**
- `status = 'active'` - Only active licenses
- `is_used = FALSE` - Not assigned to any user
- `ORDER BY generated_date DESC` - Newest first

## 🔧 Troubleshooting

### Issue: Download button not showing
**Solution:**
- Check if unused licenses exist
- Button only shows when `unusedLicenses > 0`
- Generate test licenses

### Issue: File not downloading
**Solution:**
- Check browser download settings
- Look in Downloads folder
- Check browser console for errors
- Verify servlet is deployed

### Issue: Excel file won't open
**Solution:**
- File is actually Excel-compatible CSV
- Open with Excel or LibreOffice
- Check file extension (.xls or .csv)
- Try CSV format instead

### Issue: Empty file downloaded
**Solution:**
- Check if unused licenses exist in database
- Verify query is working
- Check servlet logs
- Test with fresh licenses

### Issue: Access denied
**Solution:**
- Verify logged in as admin
- Check session is valid
- Clear cookies and re-login
- Check admin role in database
