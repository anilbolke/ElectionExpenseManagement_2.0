================================================================================
PROBLEM
================================================================================

Issue Reported:
---------------
"In user login after mapped license system directly logged out 
please redirect to dashboard."

What Was Happening:
-------------------
1. User enters license key
2. License verified and candidate activated
3. System redirects to payment-success-candidate.jsp
4. Page checks for session attributes (transactionId, candidateName)
5. These attributes don't exist (only used for payment gateway flow)
6. Page redirects to login.jsp (logout)
7. User gets logged out

Root Cause:
-----------
The license verification flow was redirecting to payment-success-candidate.jsp,
which is designed for payment gateway transactions and expects specific
session attributes that don't exist in the license flow.

================================================================================
SOLUTION
================================================================================

Changed Redirect Destination:
------------------------------
BEFORE: Redirected to payment-success-candidate.jsp
AFTER:  Redirected to user/dashboard.jsp with success message

Changes Made in LicenseServlet.java:
-------------------------------------

1. SUCCESS REDIRECT (Line ~179):
   
   BEFORE:
   -------
   response.sendRedirect(request.getContextPath() + 
       "/user/payment-success-candidate.jsp?candidateId=" + candidateId + 
       "&message=Payment+bypassed+using+license");
   
   AFTER:
   ------
   response.sendRedirect(request.getContextPath() + 
       "/user/dashboard.jsp?success=Payment+bypassed+successfully+using+license+" + 
       licenseKey.trim().toUpperCase() + ".+Candidate+activated!");

2. ERROR REDIRECTS (Lines ~133, 159, 183, 187):
   
   Changed all error redirects from:
   - /user/candidate-payment.jsp
   
   To:
   - /user/payment-with-license.jsp
   
   This ensures errors go back to the correct payment page.
