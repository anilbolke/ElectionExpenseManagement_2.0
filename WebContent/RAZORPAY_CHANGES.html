🚀 Quick Setup (5 Minutes)

⚠️ Current Mode: DEMO
System is working but using dummy payments. Follow steps below to enable real Razorpay payments.

Step 1: Get Razorpay API Keys

  • Visit Razorpay Dashboard
  • Sign up or login
  • Go to Settings → API Keys
  • Generate Test Keys
  • Copy Key ID and Key Secret

Step 2: Set Environment Variables

Windows (Command Prompt):

setx RAZORPAY_KEY_ID "rzp_test_YOUR_KEY_HERE" setx RAZORPAY_KEY_SECRET "YOUR_SECRET_HERE"

Eclipse Users:

  • Run Configurations → Environment tab
  • Add: RAZORPAY_KEY_ID = your key
  • Add: RAZORPAY_KEY_SECRET = your secret

Step 3: Restart Server & Verify

  • Restart Tomcat server
  • Visit /admin/razorpay-setup.jsp
  • Should show "✓ Configured and Ready"
