📋 5 SIMPLE STEPS:
═══════════════════════════════════════════════════════════════

STEP 1: CREATE GITHUB ACCOUNT (1 min)
---------------------------------------
🌐 Go to: https://github.com
✅ Click "Sign up"
✅ Enter email, password, username
✅ Verify email


STEP 2: CREATE NEW REPOSITORY (1 min)
---------------------------------------
✅ Click "+" icon → "New repository"
✅ Name: policy-pages
✅ Select: Public (important!)
✅ Check: "Add a README file"
✅ Click "Create repository"


STEP 3: UPLOAD HTML FILES (2 min)
---------------------------------------
✅ Click "Add file" → "Upload files"
✅ Drag and drop these 6 files:
   • index.html
   • terms-and-conditions.html
   • privacy-policy.html
   • refund-policy.html
   • shipping-policy.html
   • contact-us.html
✅ Click "Commit changes"


STEP 4: ENABLE GITHUB PAGES (30 sec)
---------------------------------------
✅ Click "Settings" tab
✅ Click "Pages" in left sidebar
✅ Source: "Deploy from a branch"
✅ Branch: "main" + "/ (root)"
✅ Click "Save"
✅ Wait 2 minutes for deployment


STEP 5: ADD URLS TO RAZORPAY (1 min)
---------------------------------------
✅ Login: https://dashboard.razorpay.com
✅ Go to: Settings → Business Details
✅ Add your GitHub Pages URLs:

   Format: https://YOUR-USERNAME.github.io/policy-pages/page.html
   
   Replace YOUR-USERNAME with your GitHub username!

   Add these 5 URLs:
   • terms-and-conditions.html
   • privacy-policy.html
   • refund-policy.html
   • shipping-policy.html
   • contact-us.html

✅ Click "Save"
✅ Wait 1-3 days for Razorpay verification
