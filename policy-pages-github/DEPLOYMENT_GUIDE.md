# 🚀 GITHUB PAGES DEPLOYMENT - STEP BY STEP GUIDE

## ⏱️ Total Time: 5 Minutes

This guide will help you deploy your policy pages to GitHub Pages for FREE!

---

## 📋 STEP 1: CREATE GITHUB ACCOUNT (1 minute)

### If you already have a GitHub account, skip to Step 2!

1. Open your browser and go to: **https://github.com**

2. Click the **"Sign up"** button (top right corner)

3. Fill in the registration form:
   - **Email address:** Your email
   - **Password:** Create a strong password
   - **Username:** Choose a username (e.g., `emsonline` or `yourcompanyname`)
   - **Email preferences:** Choose your preference

4. Verify you're human (solve the puzzle)

5. Click **"Create account"**

6. Check your email for verification code

7. Enter the 6-digit code

8. Choose options (you can skip these):
   - How many team members: Just me
   - Student or teacher: Skip
   - What do you want to do: Skip

✅ **Done!** You now have a GitHub account!

---

## 📦 STEP 2: CREATE A NEW REPOSITORY (1 minute)

1. After login, you'll see the GitHub homepage

2. Click the **"+"** icon in the top-right corner

3. Select **"New repository"**

4. Fill in the repository details:
   
   **Repository name:** `policy-pages`
   - (You can use any name, but `policy-pages` is simple)
   - ⚠️ Use lowercase and hyphens, no spaces
   
   **Description:** (optional)
   ```
   Policy pages for Razorpay compliance - Election Expense Management
   ```
   
   **Public or Private:** Select **"Public"**
   - ⚠️ Must be PUBLIC for free GitHub Pages
   
   **Initialize repository:**
   - ✅ Check **"Add a README file"**
   
5. Click **"Create repository"** (green button at bottom)

✅ **Done!** Your repository is created!

### Upload to GitHub:

## 🌐 STEP 4: ENABLE GITHUB PAGES (1 minute)

1. In your repository, click the **"Settings"** tab (top menu)

2. In the left sidebar, scroll down and click **"Pages"**

3. You'll see "GitHub Pages" settings

4. Under **"Build and deployment"**:
   
   **Source:** Select **"Deploy from a branch"**
   
   **Branch:** 
   - Dropdown 1: Select **"main"** (or "master")
   - Dropdown 2: Select **"/ (root)"**
   
5. Click **"Save"**

6. You'll see a message: "GitHub Pages source saved"

7. Wait 30 seconds, then **refresh the page**

8. You'll see a success message at the top:
   ```
   Your site is live at https://YOUR-USERNAME.github.io/policy-pages/
   ```

✅ **Done!** Your site is now live!

## 🆘 TROUBLESHOOTING

### Problem 1: GitHub Pages Not Working

**Symptom:** URLs show 404 error

**Solutions:**
1. Wait 2-3 minutes after enabling GitHub Pages
2. Make sure repository is PUBLIC
3. Check Settings → Pages shows "Your site is live"
4. Refresh your browser (Ctrl+F5)
5. Clear browser cache

### Problem 2: Razorpay Can't Access Pages

**Symptom:** Razorpay says "Policy pages are missing"

**Solutions:**
1. Test URLs in incognito/private browser window
2. Make sure repository is PUBLIC (not private)
3. Wait 5 minutes for GitHub Pages to fully deploy
4. Check URLs don't have typos
5. Make sure you're using the exact GitHub Pages URLs

### Problem 3: Repository Not Found

**Symptom:** GitHub shows "Repository not found"

**Solutions:**
1. Check repository name spelling
2. Make sure you're logged into correct account
3. Repository might be private - change to public

### Problem 4: Can't Find GitHub Pages Setting

**Symptom:** No "Pages" option in Settings

**Solutions:**
1. Make sure repository is PUBLIC
2. Check you're in correct repository
3. Try refreshing the Settings page
4. Make sure you have admin access to repository
