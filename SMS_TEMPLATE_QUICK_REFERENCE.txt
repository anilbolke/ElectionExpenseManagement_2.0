⚠️  TROUBLESHOOTING
══════════════════════════════════════════════════════════════════

Issue: "Invalid Template ID"
→ Verify template ID in SMS provider dashboard
→ Ensure template is DLT approved
→ Check if template ID is correct in SMSUtil.java

Issue: "Template Content Mismatch"
→ Message content must match DLT template exactly
→ Don't modify fixed text
→ Only variable parts can change

Issue: "DLT Rejection"
→ Check DLT portal for rejection reason
→ Modify template as per guidelines
→ Resubmit for approval

Issue: "SMS Not Delivered"
→ Check SMS balance
→ Verify mobile number format
→ Check delivery status in SMS provider dashboard
→ Verify internet connectivity
