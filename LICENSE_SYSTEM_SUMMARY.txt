HOW IT WORKS
================================================================================

LICENSE GENERATION:
1. Admin clicks "Generate Licenses"
2. System generates unique EMS keys (e.g., EMS12345, EMS67890)
3. Keys saved to database with status = 'active'
4. Admin receives list of generated keys

LICENSE USAGE:
1. User enters license key on payment page
2. System verifies:
   - License exists
   - License is active (not used)
   - License belongs to valid admin
3. If valid:
   - Mark license as 'used'
   - Map to user ID and candidate ID
   - Update payment_status = 'completed'
   - Update transaction_id = 'LICENSE_EMS12345'
   - Update is_payment_verified = true
   - Update account_status = 'active'
4. Redirect to success page

DATABASE STRUCTURE
================================================================================

Table: licenses
---------------
license_id          INT (Primary Key, Auto Increment)
license_key         VARCHAR(20) UNIQUE (e.g., "EMS12345")
is_used             BOOLEAN (true/false)
mapped_user_id      INT (Foreign Key to users)
mapped_candidate_id INT (Foreign Key to candidates)
generated_by        INT (Foreign Key to users - admin)
generated_date      TIMESTAMP (when generated)
used_date           TIMESTAMP (when used)
status              ENUM ('active', 'used', 'expired')
notes               TEXT (optional notes)

Indexes:
- idx_license_key on license_key
- idx_status on status
- idx_mapped_user on mapped_user_id
- idx_license_status on (license_key, status)

2. Clean and rebuild project
3. Restart Tomcat server
4. Clear browser cache

PROBLEM: "Invalid license key" message
SOLUTION:
- Check format: EMS followed by 5 digits
- Verify license not already used
- Check license exists in database

PROBLEM: "License used but candidate not activated"
SOLUTION:
- Check application logs for errors
- Verify database updated correctly
- Check payment_status and account_status columns

PROBLEM: Cannot generate licenses
SOLUTION:
- Verify logged in as admin (not regular user)
- Check database connection
- Verify licenses table exists
