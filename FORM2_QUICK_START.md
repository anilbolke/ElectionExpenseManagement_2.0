# Form-2 (नमुना-२) Quick Start Guide

## 🚀 5-Minute Setup & Usage

### What Is This?
Form-2 generates the official **Total Election Expense Report** with Marathi header after candidate selection, showing expenses in three parts (Self, Party, Others).

---

## 📍 Where to Find It

### Option 1: From Dashboard
```
Login → Select Candidate → Click "📋 Form-2 (नमुना-२)" → Form Opens
```

### Option 2: From Manage Candidates
```
Login → Manage Candidates → Click "📋 Form-2 (नमुना-२)" → Form Opens
```

---

## 🎯 Quick Usage

1. **Login** to your account
2. **Select** an active, payment-verified candidate
3. **Click** the purple "📋 Form-2 (नमुना-२)" button
4. **Form opens** in new tab with:
   - ✅ Your header: "नमुना-२"
   - ✅ Candidate info auto-filled
   - ✅ Blank expense fields to fill
5. **Fill in** expense amounts manually
6. **Click** "🖨️ Print PDF" button
7. **Save** as PDF using browser print dialog

---

## 📋 Form Structure

```
नमुना-२
उमेदवार - एकूण निवडणूक खर्च
(30-day submission instruction)

↓

Candidate Information (Auto-filled)
├─ Name, Constituency, Party
├─ Election Type, Date
└─ Mobile, Expenditure Limit

↓

भाग १: स्वतः केलेला खर्च (Self Expenses)
├─ Campaign Material
├─ Meetings & Rallies
├─ Vehicles & Travel
├─ Media & Ads
└─ Other → Subtotal

↓

भाग २: पक्षाने केलेला खर्च (Party Expenses)
├─ Campaign Material
├─ Meetings & Events
├─ Media & Ads
└─ Other → Subtotal

↓

भाग ३: इतर यांनी केलेला खर्च (Others Expenses)
├─ Supporters
├─ Organizations
└─ Other → Subtotal

↓

GRAND TOTAL (Part 1 + 2 + 3)
Legal Limit Reference

↓

Declaration (Bilingual)
Signature Sections
```

## ⚡ Quick Tips

- **Auto-filled**: Candidate details populate automatically
- **Manual entry**: Fill all expense amounts yourself
- **Bilingual**: Every field in Marathi and English
- **Print-ready**: Optimized for A4 paper
- **Secure**: Only you can see your candidate's form
