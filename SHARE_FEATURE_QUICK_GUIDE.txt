FEATURE 2: SHARE BUTTON FEATURE
================================================================================

WHERE:
------
• User Dashboard (user/dashboard.jsp)
• Admin Dashboard (admin/dashboard.jsp)
• Broker Dashboard (broker/dashboard.jsp)

WHAT:
-----
Floating share button at bottom-right corner that allows sharing project URL
via multiple platforms.

BUTTON APPEARANCE:
------------------
Desktop (> 768px):
  • Text + Icon: "🔗 Share"
  • Size: 14px padding
  • Position: Bottom-right (20px from edges)
  • Shape: Rounded pill
  • Color: Purple gradient
  • Shadow: Elevated

Mobile (< 480px):
  • Icon Only: "🔗"
  • Size: 50x50px circle
  • Position: Bottom-right (15px from edges)
  • Compact, non-intrusive
  • Same color and style

SHARE OPTIONS:
--------------
When clicked, modal opens with:

1. COPY TO CLIPBOARD
   • One-click copy
   • Shows "✓ Copied!" feedback
   • Works on all browsers

2. WHATSAPP SHARE
   • Opens WhatsApp with pre-filled message
   • Includes project URL
   • Works on mobile and web

3. EMAIL SHARE
   • Opens default email client
   • Pre-filled subject and body
   • Includes project URL

4. SMS SHARE
   • Opens SMS app
   • Pre-filled message with URL
   • Mobile-friendly

5. FACEBOOK SHARE
   • Opens Facebook share dialog
   • Shares project URL
   • Works in popup window

HOW TO USE:
================================================================================

FOR USERS:
----------
1. Login to your dashboard (User/Admin/Broker)
2. Look for share button at bottom-right corner
3. Click the share button (🔗 Share)
4. Modal opens with project URL
5. Choose your preferred share method:
   - Click "Copy" to copy URL
   - Click WhatsApp icon to share via WhatsApp
   - Click Email icon to share via email
   - Click SMS icon to share via text
   - Click Facebook icon to share on Facebook

FOR VIEWING FOOTER:
-------------------
1. Navigate to any proforma page
2. Scroll to bottom
3. See "Powered by emsonline.in" footer
4. Click link to visit emsonline.in (opens in new tab)

================================================================================
TROUBLESHOOTING:
================================================================================

ISSUE: Share button not appearing
SOLUTION: Clear cache, hard refresh (Ctrl+Shift+R)

ISSUE: Copy not working
SOLUTION: Check browser permissions, use manual copy

ISSUE: Share links not opening
SOLUTION: Check URL encoding, test on different device

ISSUE: Footer overlapping content
SOLUTION: Add bottom padding (40px) to page content

ISSUE: Button overlapping on mobile
SOLUTION: Check z-index and positioning values
