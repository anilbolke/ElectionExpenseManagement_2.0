───────────────────────────────

2. Visit: /admin/payment-settings.jsp
3. Click desired mode

Via SQL (Quick):
────────────────
-- Switch to QR Code:
UPDATE system_settings SET setting_value='qrcode' 
WHERE setting_key='payment_mode';

-- Switch to Razorpay:
UPDATE system_settings SET setting_value='razorpay' 
WHERE setting_key='payment_mode';

┌─────────────────────────────────────────────────────────────────┐
│ 📊 MODE COMPARISON                                              │
└─────────────────────────────────────────────────────────────────┘

RAZORPAY MODE:
──────────────
✓ Automatic payment verification
✓ Multiple payment methods (UPI, Card, Net Banking, Wallet)
✓ Instant account activation
✓ Real-time tracking
✗ Gateway fees apply
✗ Requires Razorpay account

QR CODE MODE:
─────────────
✓ Simple scan & pay
✓ Works with any UPI app
✓ No gateway fees
✓ Full control
✗ Manual verification needed
✗ Admin must check transaction IDs

QR Code Not Showing?
────────────────────
1. Check: setting_value = 'qrcode' in database
2. Verify: QrCode.jpeg exists in Document folder
3. Clear browser cache (Ctrl+F5)

Mode Not Changing?
──────────────────
1. Check database value:
   SELECT * FROM system_settings WHERE setting_key='payment_mode';
2. Clear browser cache
3. Check JSP compilation errors in logs

Admin Panel 404?
────────────────
1. Verify logged in as admin
2. Check URL path
3. Verify file exists: admin/payment-settings.jsp
