## 🔍 Database Verification Checklist

### Run These SQL Queries

#### Query 1: Check Table Exists
```sql
SHOW TABLES LIKE 'licenses';
-- Expected: 1 row returned
```
- [ ] Table exists

#### Query 2: Check Table Structure
```sql
DESCRIBE licenses;
-- Expected: 11 columns
```
- [ ] All columns present
- [ ] Data types correct
- [ ] Foreign keys defined

#### Query 3: Check Generated Licenses
```sql
SELECT COUNT(*) FROM licenses;
-- Expected: Number of licenses generated
```
- [ ] Count matches what was generated

#### Query 4: Check Available Licenses
```sql
SELECT license_key, status 
FROM licenses 
WHERE status = 'active' AND is_used = FALSE;
-- Expected: List of unused licenses
```
- [ ] Shows unused licenses

#### Query 5: Check Used Licenses
```sql
SELECT l.license_key, u.full_name, c.candidate_name, l.used_date
FROM licenses l
LEFT JOIN users u ON l.mapped_user_id = u.user_id
LEFT JOIN candidates c ON l.mapped_candidate_id = c.candidate_id
WHERE l.status = 'used';
-- Expected: List of used licenses with mappings
```
- [ ] Shows used licenses
- [ ] User names appear
- [ ] Candidate names appear

#### Query 6: Check Candidate Payment Status
```sql
SELECT candidate_id, candidate_name, payment_status, 
       transaction_id, is_payment_verified, account_status
FROM candidates
WHERE transaction_id LIKE 'LICENSE_%';
-- Expected: Candidates who used licenses
```
- [ ] Payment status = completed
- [ ] Transaction ID starts with LICENSE_
- [ ] is_payment_verified = TRUE
- [ ] account_status = active
