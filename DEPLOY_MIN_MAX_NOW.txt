╔══════════════════════════════════════════════════════════════════════╗
║                    🎮 HOW IT WORKS                                   ║
╚══════════════════════════════════════════════════════════════════════╝

STATS PANEL HEADER:
┌─────────────────────────────────┐
│ 📊 Statistics      [⇅]  [−]    │
└─────────────────────────────────┘

BUTTON 1: [⇅] or [⇄]
   • Changes stats layout
   • Desktop: 2-column ↔ 1-column
   • Mobile: 1-column ↔ 2-column

BUTTON 2: [−] or [+]
   • Minimizes/maximizes stats panel
   • [−] = Expanded (click to collapse)
   • [+] = Collapsed (click to expand)

║                    🐛 TROUBLESHOOTING                                ║
╚══════════════════════════════════════════════════════════════════════╝

ISSUE: Second button not visible
SOLUTION:
□ Clear browser cache
□ Hard refresh (Ctrl+F5)
□ Check if deployment successful
□ Verify Tomcat restarted

ISSUE: Animation is jumpy
SOLUTION:
□ Check browser console for errors
□ Verify CSS transitions are loaded
□ Try different browser
□ Clear cache and reload

ISSUE: State not persisting
SOLUTION:
□ Check localStorage is enabled
□ Try incognito mode
□ Clear localStorage manually
□ Check for errors in console

ISSUE: Buttons overlap on mobile
SOLUTION:
□ Check viewport width
□ Verify gap: 8px in styles
□ Try zooming out
□ Check responsive design
