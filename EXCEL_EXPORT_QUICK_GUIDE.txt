================================================================================
HOW TO USE (ADMIN)
================================================================================

Step 1: Login
-------------
• Login as admin (admin/admin123)

Step 2: Go to Manage Licenses
------------------------------
• Dashboard → Click "🔑 Manage Licenses"

Step 3: Download
----------------
Option A: From Statistics Card
  • Look at green "Available" card
  • Click "Download Excel" button

Option B: From Export Section (if available licenses > 0)
  • See "Export Unused Licenses" section
  • Click "Download Excel" or "Download CSV"

Step 4: Get File
----------------
• File downloads automatically
• Filename: unused_licenses_[timestamp].xls or .csv
• Open in Excel or any spreadsheet app

================================================================================
WHAT'S IN THE FILE
================================================================================

Columns:
--------
1. License Key    → EMS12345
2. Status         → active
3. Generated Date → 2025-11-16 10:30:00
4. Generated By   → Admin User

Example:
--------
License Key | Status  | Generated Date      | Generated By
EMS12345    | active  | 2025-11-16 10:30:00 | Admin User
EMS67890    | active  | 2025-11-16 10:30:01 | Admin User
EMS23456    | active  | 2025-11-16 10:30:02 | Admin User

Only Includes:
--------------
✓ Unused licenses (not assigned to any user)
✓ Active status licenses
✗ Used/assigned licenses are excluded
✗ Expired licenses are excluded

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Download button not visible
Solution: Generate some licenses first (button only shows if unused > 0)

Problem: File won't download
Solution: Check browser settings, look in Downloads folder

Problem: Excel won't open file
Solution: File is Excel-compatible, try "Open With" → Microsoft Excel

Problem: Empty file
Solution: Check if unused licenses exist, verify database connection

Problem: Access denied
Solution: Must be logged in as admin, check session

FILE FORMAT COMPARISON
================================================================================

EXCEL FORMAT (.xls)
Pros:
  • Opens directly in Excel
  • Formatted table
  • Easy to read
  • Can edit in Excel

Cons:
  • Larger file size
  • Excel-specific format

CSV FORMAT (.csv)
Pros:
  • Smaller file size
  • Universal format
  • Opens in any app
  • Easy to import

Cons:
  • Plain text format
  • No formatting
  • Needs parsing
