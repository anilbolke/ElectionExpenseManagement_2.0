┌──────────────────────────────────────────────────────────────────────────┐
│                         SESSION INFORMATION                               │
└──────────────────────────────────────────────────────────────────────────┘

After successful login, the following data is stored in session:

All Roles:
  • session.user          = Full user object
  • session.userId        = User ID number
  • session.username      = Username string
  • session.userRole      = "admin" / "broker" / "user"
  • session.fullName      = User's full name
  • session.language      = Selected language (en/hi)

Broker & User Only (Additional):
  • session.candidate     = First candidate object
  • session.candidateId   = Candidate ID
  • session.candidateName = Candidate name

┌──────────────────────────────────────────────────────────────────────────┐
│                         TROUBLESHOOTING                                   │
└──────────────────────────────────────────────────────────────────────────┘

Problem: Can't login
Solution: 
  1. Verify username spelling
  2. Check password is correct
  3. Ensure account is active
  4. Try different browser
  5. Clear browser cache

Problem: Wrong dashboard after login
Solution:
  1. Check user role in database
  2. Verify LoginServlet role detection
  3. Check redirect logic

Problem: Session expires quickly
Solution:
  1. Check web.xml session timeout
  2. Increase timeout value
  3. Re-login if needed
