   → Visit: https://razorpay.com
   → Login → Settings → API Keys
   → Copy: Key ID & Key Secret

STEP 2: SET ENVIRONMENT VARIABLES
   
   Windows Command:
   ─────────────────────────────────────────────────────────
   setx RAZORPAY_KEY_ID "rzp_test_YOUR_KEY_HERE"
   setx RAZORPAY_KEY_SECRET "YOUR_SECRET_HERE"
   ─────────────────────────────────────────────────────────

   Linux/Mac Command:
   ─────────────────────────────────────────────────────────
   export RAZORPAY_KEY_ID="rzp_test_YOUR_KEY_HERE"
   export RAZORPAY_KEY_SECRET="YOUR_SECRET_HERE"
   ─────────────────────────────────────────────────────────

STEP 3: RESTART SERVER
   → Stop Tomcat
   → Start Tomcat
   → Done! ✅
