5. SECURITY FLOW
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│                         LICENSE SECURITY CHECKS                          │
└─────────────────────────────────────────────────────────────────────────┘

GENERATION (Admin):
  1. ✓ Check user session exists
  2. ✓ Check user role = 'admin'
  3. ✓ Validate count (1-1000)
  4. ✓ Generate unique keys (no duplicates)
  5. ✓ Insert with status = 'active'

VERIFICATION (User):
  1. ✓ Check user session exists
  2. ✓ Validate license key format (EMS + 5 digits)
  3. ✓ Check candidate belongs to logged-in user
  4. ✓ Query: status='active' AND is_used=FALSE
  5. ✓ Atomic update (prevent race condition)
  6. ✓ Mark as used with user/candidate mapping
  7. ✓ Update payment status in single transaction
