╚══════════════════════════════════════════════════════════════════════╝

FOR USERS:

1. Go to Dashboard (User/Admin/Broker)

2. Find "📊 Statistics" section in left sidebar

3. Click toggle button [⇅] to switch layout:
   
   DESKTOP:
   • Default [⇅]: 2-column horizontal grid
   • After click [⇄]: 1-column vertical list
   
   MOBILE:
   • Default [⇅]: 1-column vertical (easy to read)
   • After click [⇄]: 2-column compact

4. Your choice is automatically saved!

╔══════════════════════════════════════════════════════════════════════╗
║                    ⚠️ TROUBLESHOOTING                                ║
╚══════════════════════════════════════════════════════════════════════╝

ISSUE: Toggle button not visible
SOLUTION:
□ Clear browser cache
□ Hard refresh (Ctrl+F5)
□ Check if files are deployed
□ Verify Tomcat restart completed

ISSUE: Toggle doesn't switch layout
SOLUTION:
□ Check browser console for errors
□ Verify JavaScript is enabled
□ Clear localStorage and try again
□ Check if element IDs are correct

ISSUE: Layout not remembered after refresh
SOLUTION:
□ Check if localStorage is enabled
□ Try different browser
□ Check for localStorage quota issues

ISSUE: Mobile view not showing vertical
SOLUTION:
□ Verify screen width is <768px
□ Check media query in CSS
□ Clear cache and reload
