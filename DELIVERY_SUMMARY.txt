DATABASE SCHEMA
================================================================================

Table: licenses
──────────────────────────────────────────────────────────────────────────
Columns:
  • license_id (PK, AUTO_INCREMENT)
  • license_key (VARCHAR(20), UNIQUE) → "EMS12345"
  • is_used (BOOLEAN) → true/false
  • mapped_user_id (FK → users.user_id)
  • mapped_candidate_id (FK → candidates.candidate_id)
  • generated_by (FK → users.user_id, admin)
  • generated_date (TIMESTAMP) → when created
  • used_date (TIMESTAMP) → when used
  • status (ENUM: 'active', 'used', 'expired')
  • notes (TEXT) → optional notes

Indexes:
  • PRIMARY KEY on license_id
  • UNIQUE KEY on license_key
  • INDEX on status
  • INDEX on mapped_user_id
  • COMPOSITE INDEX on (license_key, status)

Foreign Keys:
  • mapped_user_id → users(user_id) ON DELETE SET NULL
  • mapped_candidate_id → candidates(candidate_id) ON DELETE SET NULL
  • generated_by → users(user_id) ON DELETE CASCADE
